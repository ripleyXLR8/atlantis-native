Atlantis Native 0.6.0: Atlantis III playable from start to end.

You need your own copy of the games: Atlantis Native contains no game
data. Play the three games in your browser at
https://ripleyxlr8.github.io/atlantis-native/ or
https://ripleyxlr8.itch.io/atlantis-native.

## New in 0.6.0

### Atlantis III: The New World (2001)

- **The whole game plays**, on Windows, macOS, Linux and in the browser:
  the intro, the start page and its five players, the Hoggar, the Land of
  the Dead and the other worlds, every dialog with its voices, 3D heads,
  lip-sync and subtitles, the inventory, the maps, every puzzle, the
  ending and the credits.
- **The original's own menus and options**: save and load with their
  thumbnails, the volumes, the screen size (640 x 480, 800 x 600 or 1024 x
  768), 16 or 32 bits, smoothing, the crosshair, subtitles. A size or depth
  change applies when the menu closes, as in the original.
- **The edition**: GOG.com's French release (*Atlantis 3 - The New
  World*), the only one the project knows. Other editions (GOG.com's in
  other languages, the retail CDs and DVDs) are unknown and untested:
  their program is refused with its size and MD5, so that it can be
  reported on GitHub and added.
- **On the desktop** the game library finds GOG.com's installation and
  plays it in its own window, as Atlantis II; the saves and the options
  file `Atlantis3.cfg` are kept in the player's data folder (`atlantis3`),
  never in the game's folder, and F12 writes a screenshot there. Alt+Enter
  or F11 switches full screen. **In the browser** pick the installation
  folder; the saves stay in the browser.
- **What was checked against the original**: the port follows the original
  program's code, and automated tests replay what that code computed under
  emulation, step for step: the whole story played with the mouse from a
  new game to the credits (every script variable, flag and checkpoint save
  after every step); every puzzle's board (the Hoggar's, the market and the
  garden, Paleo's wolves, tiger, hunt and altar, the corridor's doors, the
  unicorn, the tower race, the game boy, the star room, the drawer walls);
  the maps, the travels, the ending and the credits; the menu pages at the
  three screen sizes, their tooltips and the save thumbnails; the text
  layout of every dialog line, the dialogs' camera, heads and lip-sync;
  the videos, the panoramas and the place sprites in 16 and 32 bits; Escape
  in each part of the game.
- **How much it has been played**: beyond those replays, Atlantis III has
  been tested by the developer's own play, not yet by many players. Please
  report anything that looks or sounds wrong, with the place and what you
  did.
- **Known differences**: the texts are drawn from the game's own font at
  the widths Windows gives it, but their antialiased pixels are Atlantis
  Native's own (16 and 32 bits); the click on the in-game menu's Back
  button may also act in the view behind it (checked since: the original
  never does, and the port matches it after 0.6.0); the window, full screen and the display switch are the port's.
  The [player's guide](https://github.com/ripleyXLR8/atlantis-native/blob/main/docs/GUIDE.md#atlantis-iii)
  lists them all.
- Atlantis III has no HD mode and no port options menu (F10): it plays as
  the original does. The PortMaster build stays the first game only.

### Atlantis: The Lost Tales and Atlantis II

- Nothing changes in how they play. The game library now holds the three
  games, and its first start offers each one found on the computer.

## Downloads

| System | File |
|---|---|
| Windows 10 and later, 64-bit | `atlantis-native-windows-x64.zip` |
| Windows 11 on ARM | `atlantis-native-windows-arm64.zip` |
| macOS 11 and later, Apple Silicon | `atlantis-native-macos-arm64.dmg` |
| macOS 11 and later, Intel | `atlantis-native-macos-x64.dmg` |
| Linux x86-64 (glibc 2.35+, ALSA) | `atlantis-native-linux-x64.tar.gz` |
| Linux 64-bit ARM, e.g. Raspberry Pi 4 or 5 | `atlantis-native-linux-arm64.tar.gz` |
| Handhelds with PortMaster (64-bit ARM), the first game | `atlantis-native-portmaster.zip` |
| Web (the three games) | play online, or `atlantis-native-web.zip` on the [nightly release](https://github.com/ripleyXLR8/atlantis-native/releases/tag/nightly) |

The builds are not signed: Windows SmartScreen may warn the first time
("More info", then "Run anyway"). On macOS, open the app once, then go to
System Settings → Privacy & Security and click "Open Anyway".

See the [README](https://github.com/ripleyXLR8/atlantis-native#readme)
(its table of supported editions) and the
[player's guide](https://github.com/ripleyXLR8/atlantis-native/blob/main/docs/GUIDE.md).
