Atlantis Native 0.8.0: the original 2004 CD program of Atlantis
Evolution as a preview, the French retail CD of Atlantis III, and CD
images read in the browser.

You need your own copy of the games: Atlantis Native contains no game
data. Play the games in your browser at
https://ripleyxlr8.github.io/atlantis-native/ or
https://ripleyxlr8.itch.io/atlantis-native.

## New in 0.8.0

### Atlantis Evolution: the 2004 CD (preview)

- **The original 2004 program** (The Adventure Company's CD, English) is
  in the game library as *Atlantis Evolution (2004), CD, English*,
  beside GOG.com's 2012 edition, on the desktop and in the browser. It
  is Cryo's own engine, grown from Atlantis III's, and Atlantis Native
  plays it with its Atlantis III engine: the logos, start page, menus,
  saves, panoramas, chapter scripts, dialogs, inventory, music, Bink
  films, the ship's pitching and its eight mini-games, each traced to
  the original's code and checked by automated tests.
- **It is a preview:** it has not yet been played through from start to
  end. Reports are welcome.
- Pick the folder its installer filled (the one holding
  `Atlantis Evolution.exe` and `cd0` to `cd4`). The CDs themselves hold
  only the installer's archives, so the installed folder is needed.
- A new bug fix, `fix_smooth_turn` (on by default, off with
  `--original`): the view is drawn between the original's 25 Hz look
  steps, so turning is smooth on today's screens.

### Atlantis III

- **The French retail CD (2001, three CDs)** is recognised and plays, on
  the desktop and in the browser. Its program is older than GOG.com's
  (2003), and Atlantis Native follows its differences: it asks for disc
  1, 2 or 3 as the scenes need them (GOG.com's program skips that test),
  and it draws the scarab's case, which GOG.com's program misses in
  French. Pick the installed folder with the images or copies of the
  three CDs. Thanks to Barbarian_brother, who sent the discs.
- **A new bug fix, `fix_32bits`** (on by default, off with `--original`
  or in `settings.ini`): the original starts in 16-bit colours, because
  no shipped `Atlantis3.cfg` names a colour depth. Atlantis Native now
  starts in 32 bits; a 16-bit choice on the options page is kept.

### The web version

- **CD images are read in the browser** (`.iso`, `.bin`, `.img`, `.mdf`,
  `.nrg`), a part at a time, for the CD editions of Atlantis I, II and
  III: pick the folder holding them (with the installed game for
  Atlantis II and III), or, for the first game, the image files
  themselves. Copies of the discs still work.
- **Cinematics are read by parts** in Atlantis II and III: starting a
  film no longer stops the page and the sound for a moment.
- **Firefox:** Atlantis III and both editions of Atlantis Evolution were
  played in Firefox as well as in Edge.

## Downloads

| System | File |
|---|---|
| Windows 10 and later, 64-bit | `atlantis-native-windows-x64.zip` |
| Windows 11 on ARM | `atlantis-native-windows-arm64.zip` |
| macOS 11 and later, Apple Silicon | `atlantis-native-macos-arm64.dmg` |

| Linux x86-64 (glibc 2.35+, ALSA) | `atlantis-native-linux-x64.tar.gz` |

The builds are not signed: Windows SmartScreen may warn the first time
("More info", then "Run anyway"). On macOS, open the app once, then go to
System Settings → Privacy & Security and click "Open Anyway".
