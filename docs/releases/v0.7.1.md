Atlantis Native 0.7.1: the Polish CD of Atlantis II, and a finer pass on
how the first game plays.

You need your own copy of the games: Atlantis Native contains no game
data. Play the four games in your browser at
https://ripleyxlr8.github.io/atlantis-native/ or
https://ripleyxlr8.itch.io/atlantis-native.

## New in 0.7.1

### Atlantis II

- **The Polish CD (1999, 4 CDs)** is recognised and plays, with its
  Polish voices, texts and font. Its program is a build of its own,
  version 1.01's code, and its texts are drawn in the Central European
  character set (Windows-1250), so the Polish letters (ą, ę, ł, ż…) show
  as they should. Install it as the French CD: the installed folder, with
  the images or copies of the four CDs; in the browser, copies of the
  CDs. Thanks to the owner of the edition, who sent its discs
  ([#8](https://github.com/ripleyXLR8/atlantis-native/issues/8)).

### Atlantis: The Lost Tales

A finer pass on how the original plays, from eight rounds of automated
review of the first game against the original program. Each difference
found was checked against the original's code, and the port now does
what the original does, with a test that replays it.

- **Clicks and the mouse** are read as the original reads them: a press
  is taken when it happens, Windows' double click is paired in one place,
  and every loop reads the game's pointer rather than the system cursor.
  This affects the puzzles, the inventory bar, the menus and the films.
- **After a timed scene change, the first click on an exit moves at
  once**, as in the original, instead of being swallowed.
- **Puzzles**: the ogre puzzle keeps its path from one play to the next,
  as in the original; the crab, the hexagon, Muria, the throne and two
  sliding puzzles take a click at the pointer the original uses.
- **The bow** taken from the inventory bar is in the hand before the bar
  slides out.
- **Sound**: volumes follow the original's sound library; the options'
  channel test plays where the original plays it.
- **Two new bug fixes, on by default** (off with `--original`, or each
  set to `off` in `settings.ini`):
  - `fix_any_disc`: in chapter 79, the palace's back gate leads into the
    day city. In the original it looks for a file on the wrong disc and
    shows an error box.
  - `fix_load_order`: the LOAD list shows the checkpoints in chapter
    order. The original's sort puts, for example, chapter 11 before
    chapter 9.
- **A new option, `background_run`** (on by default, desktop builds):
  the game goes on while its window is not the active one. Off, and with
  `--original`, it pauses as the original does.
- **`--original`** now also starts with the original's OMNI 3D mode and
  volumes.

### All games

- **The game library** has the web page's look (night sky, silver title,
  gold names), drawn at the window's resolution.

## Downloads

| System | File |
|---|---|
| Windows 10 and later, 64-bit | `atlantis-native-windows-x64.zip` |
| Windows 11 on ARM | `atlantis-native-windows-arm64.zip` |
| macOS 11 and later, Apple Silicon | `atlantis-native-macos-arm64.dmg` |
| macOS 11 and later, Intel | `atlantis-native-macos-x64.dmg` |
| Linux x86-64 (glibc 2.35+, ALSA) | `atlantis-native-linux-x64.tar.gz` |
| Linux 64-bit ARM, e.g. Raspberry Pi 4 or 5 | `atlantis-native-linux-arm64.tar.gz` |
| Handhelds with PortMaster (64-bit ARM), the first game | `atlantis-native-portmaster.zip` |
| Web (the four games) | play online, or `atlantis-native-web.zip` on the [nightly release](https://github.com/ripleyXLR8/atlantis-native/releases/tag/nightly) |

The builds are not signed: Windows SmartScreen may warn the first time
("More info", then "Run anyway"). On macOS, open the app once, then go to
System Settings → Privacy & Security and click "Open Anyway".

(its table of supported editions) and the
