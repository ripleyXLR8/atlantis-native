# Atlantis Native 0.8.1 (draft)

## Portable mode, `--data-dir` and `--help`

- **Portable mode:** put an empty file named `portable.txt` (or a folder
  named `data`) next to the program (on macOS, next to `Atlantis
  Native.app`) and the saves, settings, game library and log go in that
  `data` folder, made if missing, instead of your user folder. Deleting
  the program's folder then removes the game's files too. Without the
  file or the folder nothing changes: your saves stay where they were.
  To move them, make the `data` folder and copy your user folder's
  contents into it (see the [guide](../GUIDE.md#where-the-files-live)).
- **`--data-dir <folder>`** keeps everything of that run in `<folder>`,
  over every other rule; then come `ATLANTIS_NATIVE_DATA`, the portable
  mode and the per-user folder.
- **`--help`** (or `-h`) prints every option, one line each (the
  development ones apart), and these rules.
