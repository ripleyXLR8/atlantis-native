Atlantis Native 0.7.0: Atlantis Evolution (2004) playable from start to
end, the fourth game of the program.

You need your own copy of the games: Atlantis Native contains no game
data. Play the four games in your browser at
https://ripleyxlr8.github.io/atlantis-native/ or
https://ripleyxlr8.itch.io/atlantis-native.

## New in 0.7.0

### Atlantis Evolution (2004)

- **The whole game plays**, on Windows, macOS, Linux and in the browser:
  the two splash screens, the main menu (new game, continue, the chapters
  to load, the options, the credits), then the whole story through the
  warp views and their scripts, the videos, the dialogs with their voices
  and talking heads, the inventory, the documents, the saves and the
  chapter saves, the deaths and the end.
- **The edition**: GOG.com's release, in its five languages: English,
  French, German, Italian and Spanish. The language played is the one
  GOG.com installed, as in the original, which has no language menu;
  `language` in the game's `settings.ini`, `--lang` on the command line
  or `?lang=` in the web page's address chooses another. It is the only
  edition the project knows: the Steam release and the retail discs are
  untested, and their program is refused with its size and MD5. If you
  have one, please report that size and MD5 on GitHub so it can be
  added.
- **A new engine**: GOG.com's edition is a Tetraedge Engine program, not
  Cryo's, so Atlantis Evolution has an engine of its own in Atlantis
  Native, which runs the original's own Lua scripts. It is drawn by the
  graphics card (OpenGL 3.3 or OpenGL ES 3.0, WebGL 2 in the browser),
  or by the processor when no such context can be made (`renderer = cpu`
  in `settings.ini`).
- **The original's sound, to the sample**: the music, voices and effects
  are decoded by a port of the original's Vorbis 1.2.0 decoder, with the
  game's own arithmetic, and mixed as the original's OpenAL software
  mixer mixes them; the videos are decoded to the original's pixels.
- **The original's menus and options**: the four volumes, the inverted
  look, the compass and the permanent help, kept in `options.xml` beside
  the saves. The saves are the original's own files, kept in the
  player's data folder (`atlantis4`), never in the game's folder.
- **The window**: the game starts in full screen, as the original;
  `fullscreen = off` starts it in a window that can be resized, and F11
  or Alt+Enter switches. The interface is laid out on any window size as
  the original lays it out on its own.
- **Text spacing and line wrapping match the original**: the original's
  kerning table is reproduced exactly, quirks included.
- **In the game library**: it finds GOG.com's installation on the
  desktop, and **Add a game folder...** takes the folder holding
  `Atlantis Evolution.exe`. In the browser, pick that folder: the files
  are read ahead so the sound plays without gaps, and the saves stay in
  the browser.
- **What was checked against the original**: the port follows the
  original program's code, and automated tests check it against what
  that code gives: the whole story replayed from a new game to the end,
  chapter by chapter, against the original's scripts; the scripts
  against the reference Lua; the layout formulas under emulation; every
  picture, sound and video decoded to the same pixels and samples as the
  original's decoders. The graphics card renderer was compared with
  frames captured live from the original running, and the differences
  found there (the markers, the cursor, the clipping of text boxes, the
  planks' rotation, the 1.01 pictures) are fixed.
- **Known limits**: beyond those checks, Atlantis Evolution has been
  tested by the developer's own play, not yet by many players; please
  report anything that looks or sounds wrong, with the place and what
  you did. In the browser it has been tried in Chrome and Edge only
  (Firefox, Safari and phones are untested). It is not part of the
  PortMaster build. A few narrow choices of the port are still to be
  checked against the original. Atlantis Native's options menu (F10)
  and HD mode do not apply to it: it plays as the original does.

### Atlantis III: The New World

- **GOG.com's Spanish edition plays normally from its first start**: a
  new bug fix, `fix_warpres_cd`, on by default. Its `Atlantis3.cfg`
  asks for 1024-pixel panoramas the installation does not ship, so in
  the original the first session showed the cube's debug colours, no
  place animation and no film but the intro, until the options page was
  opened. The fix applies the options page's own rule at start-up.
  `--original` (or `fix_warpres_cd = off` in `settings.ini`) keeps the
  original's behaviour, broken first session included.

### All games

- **Windows**: the program now asks for a 16 MiB main-thread stack, as
  the games get on the other systems, instead of Windows' 1 MiB default.

("More info", then "Run anyway"). On macOS, open the app once, then go to
System Settings → Privacy & Security and click "Open Anyway".
