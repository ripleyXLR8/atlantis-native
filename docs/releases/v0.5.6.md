Atlantis Native 0.5.6: start in full screen.

You need your own copy of the games: Atlantis Native contains no game
data. Play both games in your browser at
https://ripleyxlr8.github.io/atlantis-native/ or
https://ripleyxlr8.itch.io/atlantis-native.

## New in 0.5.6

### Atlantis: The Lost Tales

- **Start in full screen**: a new row of F10's options menu, after the
  HD options (Off by default). On, the game's window opens in full
  screen every time; when the game is chosen in the game library, its
  window goes to full screen as the game starts. It is kept in
  `settings.ini` with the edition's other settings, so it survives
  updates. Switching full screen while the game runs changes it too
  (F, F11 or Alt+Enter, or the system's own way, such as macOS's green
  button): the window opens the way you left it, as Atlantis II already
  does. `--fullscreen` still opens in full screen whatever the option
  says, without changing it. The browser lets a page go full screen only
  on a key or a click, so the web version has no such row: press F or
  use the page's button. Thanks to derRichter for the
  [request on GitHub](https://github.com/ripleyXLR8/atlantis-native/issues/7).
- **The options menu's rows** are 20 pixels high instead of 24 on the
  desktop (scaled with the window), so that the menu, with its new row,
  keeps a margin on the 640x480 screen. The web version's menu is
  unchanged.
- **Fixed: HD options undone at the next start.** After a change of the
  HD options in F10 (panorama filter, sharpening, interface, sharp
  subtitles, widescreen, video sides), a change in the game's own
  options page (subtitles, OMNI 3D mode) or sound page wrote back to
  `settings.ini` the HD options the game had started with: the next
  start had lost the F10 choices. The game's own pages now keep them.

## Downloads

| System | File |
|---|---|
| Windows 10 and later, 64-bit | `atlantis-native-windows-x64.zip` |
| macOS 11 and later, Apple Silicon | `atlantis-native-macos-arm64.dmg` |
| macOS 11 and later, Intel | `atlantis-native-macos-x64.dmg` |
| Linux x86-64 (glibc 2.35+, ALSA) | `atlantis-native-linux-x64.tar.gz` |
| Linux 64-bit ARM, e.g. Raspberry Pi 4 or 5 | `atlantis-native-linux-arm64.tar.gz` |
| Web (both games) | play online, or `atlantis-native-web.zip` on the [nightly release](https://github.com/ripleyXLR8/atlantis-native/releases/tag/nightly) |

The builds are not signed: Windows SmartScreen may warn the first time
("More info", then "Run anyway"). On macOS, open the app once, then go to
System Settings → Privacy & Security and click "Open Anyway".

and the [player's guide](https://github.com/ripleyXLR8/atlantis-native/blob/main/docs/GUIDE.md)
(its [full screen](https://github.com/ripleyXLR8/atlantis-native/blob/main/docs/GUIDE.md#full-screen)
section for the new option).
