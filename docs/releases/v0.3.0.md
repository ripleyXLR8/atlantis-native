Atlantis Native 0.3.0: full screen everywhere, and the game in your
browser, now drawn by the graphics card and online at
**https://ripleyxlr8.github.io/atlantis-native/**.

You need your own copy of the game: Atlantis Native contains no game
data.

## New in 0.3.0

- **Play in your browser**: the web version is online at
  https://ripleyxlr8.github.io/atlantis-native/ (Chrome, Edge, Firefox or
  Safari). Choose your game folder: its files are read inside your
  browser and never sent anywhere; the saves stay in that browser.
- **Full screen**: F11 or Alt+Enter switches full screen on and off, on
  Windows, macOS, Linux and in the browser (which also has a "Full
  screen" button).
- **A much lighter web version**: the frames go to the graphics card
  through WebGL 2, and the HD panorama is drawn there with the engine's
  own formulas, pixel for pixel the same picture. The browser's work per
  frame is about halved, and full screen no longer slows it down.
- **A new web page** in the game's spirit to start from.
- Screenshots in the README.

The game itself plays as in 0.2.0, with the same supported editions:
the English 2001 CD, the 1997 CDs (English, French, German, Dutch,
Swedish, Spanish, Italian), Cryo's patch 1.01 over them, and the five
GOG.com releases.

## Downloads

| System | File |
|---|---|
| Windows 10 and later, 64-bit | `atlantis-native-windows-x64.zip` |
| macOS 11 and later, Apple Silicon | `atlantis-native-macos-arm64.dmg` |
| Linux x86-64 (glibc 2.35+, ALSA) | `atlantis-native-linux-x64.tar.gz` |
| Web | play online, or `atlantis-native-web.zip` on the [nightly release](https://github.com/ripleyXLR8/atlantis-native/releases/tag/nightly) |

The builds are not signed: Windows SmartScreen may warn the first time
("More info", then "Run anyway"). On macOS, open the app once, then go to
System Settings → Privacy & Security and click "Open Anyway".

See the [README](https://github.com/ripleyXLR8/atlantis-native#readme)
and the [player's guide](https://github.com/ripleyXLR8/atlantis-native/blob/main/docs/GUIDE.md).
