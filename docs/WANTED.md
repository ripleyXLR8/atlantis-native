# Atlantis Native: wanted editions

[Back to the README](../README.md)

Atlantis Native plays an edition only once its program file has been
identified: the size and checksum of `atlantis.exe` (or the program of
the later games), and where needed the tables and texts it ships. An
edition nobody has described is refused with its identifiers, so that it
can be added. This page lists, for each of the five games, the editions
the project knows of but has never checked on an original disc.

If you own one of them, the box and the discs are enough to help: see
[How to help](#how-to-help). **Never send or upload a copy of a game or
a disc image**, only photos, file listings and checksums.

Colours:

| | Meaning |
|---|---|
| 🟢 | Already supported or tried |
| 🔴 | **Most wanted**: would let the most players start their copy, or let the project check a program file it has only read about |
| 🟠 | Wanted, in any order |
| 🟡 | Supported, but a clean dump would repair a part of it |
| ⚪ | Not confirmed: the edition probably exists, but nobody has described a box yet |

How to read the tables: the barcode is the EAN or UPC under the box's
bar code; the ring code is the text engraved in the disc's inner ring,
around the hole (read it under a lamp, tilting the disc). A Redump entry
is a public description of a pressed disc on [Redump.org](http://redump.org/),
with its sizes and checksums but no data: when a Redump entry exists, a
dump of the same disc is already described, and what the project lacks
is the program file's own checksum and date.

List as of November 2026.

## How to help

What helps, from the most useful to the least:

1. **The program file's identifiers**, taken from your own original
   disc: its name, size in bytes, date, MD5 and SHA-1. The program file
   is `atlantis.exe` on disc 1 (*Atlantis: The Lost Tales*),
   `atlantis2.exe` on disc 1 or in the installed folder (*Atlantis II*),
   `Atlantis3.exe` or `Game.exe` in the installed folder (*Atlantis
   III*), `Atlantis Evolution.exe` in the installed folder (*Atlantis
   Evolution*), `The secrets of Atlantis.exe` at the DVD's root (*The
   Secrets of Atlantis*). The same for the main archives (`BIGCD*.BIG`,
   `*.cab`) is welcome.
2. **A file listing** of each disc: names, sizes and dates, for
   example `dir /s D:\ > disc1.txt` on Windows, or `ls -lR` on Linux or
   macOS.
3. **Photos** of the back of the box (with its barcode) and of each
   disc's inner ring, where the ring code is engraved.
4. **A dump submitted to [Redump.org](http://redump.org/)**, if you
   know how: Redump keeps only the description of the disc (sizes,
   checksums, ring codes), never its data.

To compute the checksums:

- Windows (PowerShell): `Get-FileHash -Algorithm MD5 "D:\atlantis.exe"`,
  then again with `-Algorithm SHA1`.
- Windows (command prompt): `certutil -hashfile D:\atlantis.exe MD5`.
- Linux: `md5sum` and `sha1sum`; macOS: `md5` and `shasum`.

For *Atlantis: The Lost Tales*, Atlantis Native does most of this
itself: when it refuses a folder, **Report it on GitHub** opens a new
issue filled in with the identifiers of the files (see
[Supported editions](GUIDE.md#supported-editions)); add where your copy
comes from before you submit it.

Send what you found in a
[new issue on GitHub](https://github.com/ripleyXLR8/atlantis-native/issues/new),
with the edition's title, country and barcode.

**Please do not send or upload copies of the games, of their files or of
disc images**, not even of a single program file: the games are still
sold, and their files belong to their publisher. Only metadata,
checksums and photos are needed, and only from a disc you own.
