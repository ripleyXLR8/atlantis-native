Atlantis Native is a new engine for Atlantis: The Lost Tales. It does not include the game itself: the pictures, videos, voices and music belong to the game's publisher, so it plays them from your own copy of the game.

Choose the folder of your game:

  • GOG.com: the folder where the game is installed.
  • CD: a folder holding atlantis.exe and BIGCD1.BIG to BIGCD4.BIG, copied from the four discs (each disc holds one BIGCD file).

The files stay on your computer: the browser only reads them. The players and checkpoints are kept in this browser. How to get the game files
